[Make the Judge Laugh in One Line](https://make.fun/c/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21)

## The line

> My washing machine ate one sock and left a ransom note written in lint.

71 characters. A familiar setup (the sock-eating washing machine) that breaks
into something nobody sees coming: a ransom note — written in lint.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
